# BrickCollector

*[English version](README.md)*

Учёт коллекции LEGO® со справочником BrickLink внутри. Работает на своей машине
или аддоном Home Assistant. Наружу ничего не уходит.

Отвечает на вопросы, которые коллекция задаёт сама. Этот набор у меня уже есть?
Сколько чёрных кирпичиков 2×4 и в каких они коробках? Какой фигурки не хватает
вот в этом наборе и во сколько обошлась вся полка?

## Что умеет

**Справочник.** Все наборы, минифигурки и детали, которые знает BrickLink, —
175 тысяч предметов с составом, цветами, темами и годами выпуска. Поиск по
названию и артикулу, отбор по типу, теме и году. Обновляется из интерфейса
тогда, когда вам это нужно.

**Наборы в коллекции.** При добавлении набор копируется целиком: детали,
минифигурки, детали внутри этих минифигурок и вложенные поднаборы по всей
цепочке. Каждый экземпляр — отдельная запись: три одинаковых набора это три
набора с тремя ценами, тремя местами хранения и тремя историями.

**Что потерялось.** Утерянным можно пометить что угодно, вплоть до одной детали
внутри минифигурки внутри набора. Набор после этого сам знает, что он
некомплектен, — открывать его для этого не нужно. Потерянная запасная деталь
некомплектом не считается: без неё набор остаётся полным.

**Минифигурки.** Фигурка внутри набора и купленная отдельно — одна и та же
фигурка, поэтому в списке у неё одна карточка на обе. Внутри видно, в каких
наборах она стоит, из чего собрана и какими отдельными экземплярами вы
владеете. У каждого отдельного экземпляра своя мета.

**Детали.** Считаются по всей коллекции, а не перечисляются по коробкам:
сколько всего, сколько в наборах, сколько внутри минифигурок, сколько
россыпью — и из каких экземпляров каждая.

**Ваши пометки.** Дата и стоимость покупки, источник, место хранения; теги и
статусы, которые вы заводите сами; произвольная заметка. Неудаляемых статусов
всего два — «Коробка» и «Инструкция», они идут в комплекте.

**Аналитика.** Что в коллекции, во сколько обошлось, и то же самое в разрезе
тем и годов выпуска. Числа кликабельны: клик открывает раздел, отфильтрованный
ровно по тому, что в этом числе посчитано.

**Ссылки.** Кнопки на BrickLink, Rebrickable и Brickset на каждой детальной
странице плюс два блока под ваши собственные ресурсы. Адреса задаются
паттернами, их можно править.

**Два языка.** Русский и английский, переключаются в настройках. Названия из
справочника остаются такими, какими их пишет BrickLink: это данные, и поиск
идёт по ним же.

## Установка

Аддоном Home Assistant — проще всего, и ради этого всё и затевалось:

1. Добавьте репозиторий `https://github.com/dimquea/hassio` в **Настройки →
   Дополнения → Магазин дополнений → ⋮ → Репозитории**.
2. Установите **BrickCollector** и запустите. При первом запуске он скачает
   справочник и развернёт его; в журнале видно, чем он занят.
3. Откройте **BrickCollector** в боковом меню.

На своей машине понадобится PHP 8.2 или новее с SQLite и веб-сервер,
направленный на `public/`:

```bash
git clone https://github.com/dimquea/BrickCollector.git
cd BrickCollector
composer install
npm ci && npm run build
cp .env.example .env && php artisan key:generate
php artisan migrate
php artisan catalog:import --download
```

## Про доступ

Учётных записей и паролей в BrickCollector нет, и это намеренно: он рассчитан
на домашнюю сеть или на панель Home Assistant, которая и сторожит вход. Аддон
не выставляет наружу ни одного порта — панель единственная дверь внутрь. В
открытый интернет в таком виде выставлять не стоит.
